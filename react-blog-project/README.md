# React Project - Create Blog

# Techs Used in this project:
* appWrite - As Backend & Database Resource
* TinyMCE
* React Hook Form
* React Router
* React-Redux Toolkit
* Html-React-Parser

# Install the above library to the project:
> npm install @reduxjs/toolkit react-redux react-router-dom appwrite @tinymce/tinymce-reacthtml-react-parser react-hook-form
